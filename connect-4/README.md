# Connect 4

A two-player (human vs. human) Connect 4 game written in plain JavaScript, HTML and CSS.

## How to play

Open `index.html` in any web browser — no build step or server needed.

- Players take turns clicking a column; the disc drops to the lowest empty spot.
  Red and Yellow alternate.
- Four in a row (horizontal, vertical, or diagonal) wins and is outlined.
- If the board fills with no winner, the game is a draw.
- The scoreboard tracks wins and draws. **New Game** starts another round (the
  starting player alternates each round); **Reset Scores** clears the tally.
