# Tic Tac Toe

A two-player (human vs. human) Tic Tac Toe game written in plain JavaScript, HTML and CSS.

## How to play

Open `index.html` in any web browser — no build step or server needed.

- Players take turns clicking empty squares; X and O alternate.
- Three in a row (horizontal, vertical, or diagonal) wins and is highlighted.
- If all nine squares fill with no winner, the game is a draw.
- The scoreboard tracks wins and draws. **New Game** starts another round (the
  starting player alternates each round); **Reset Scores** clears the tally.
